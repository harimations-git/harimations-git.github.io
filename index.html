Projects

PetPath | Full-Stack Cloud Adoption Platform

Designed and delivered PetPath, an end-to-end pet adoption platform consisting of a React Native mobile application, React and TypeScript management portal, and serverless AWS backend. Built cloud services using API Gateway, Lambda, DynamoDB, Cognito, S3 and SES to support authentication, pet matching, data persistence, media storage, moderation and notifications.

Managed the project through Jira using a Scrumban workflow, translating requirements into user stories, acceptance criteria, epics and focused development sprints. Features were delivered iteratively and validated through automated, API, integration, security, performance and user acceptance testing.

MUSH | Handcrafted 2D Unity Adventure

Developed and designed MUSH, an in-progress 2D Unity game in C#, combining responsive player controls, state-based gameplay systems, URP 2D visuals, and handcrafted Tilemap levels.

3D Action Game Prototype | Godot & Blender

I’m building this as a long-term passion project using an open-source workflow centred around Godot and Blender. Development is starting with the player first, creating the movement, interaction and animation systems that will form the foundation of the wider game.

Godot is being used for the gameplay side, including momentum-based movement, grappling, ledge interactions, wall movement, projectiles, animation blending and custom visual effects. Blender is used alongside it for modelling, rigging and character animation, with assets and animations exported into Godot and refined in-engine so movement, physics and animation work together as one system.

The project is planned to grow from this player-focused prototype into a fully fledged 3D game, with the environments, mechanics and broader game design being built around these core systems.

HEdClass | Educational Management System

HEdClass is a full-stack educational management system designed to streamline complex university workflows. Built with JavaScript, Node.js, Express, MySQL and EJS, the system manages academic structures, user roles and student classifications through secure backend logic, relational database design and role-based access control.

The project strengthened my experience in full-stack development, REST-style server architecture, relational database design, authentication and dynamic SQL-driven reporting.

WHITE SPACE | Solo Animated Short Film

Conceived and produced WHITE SPACE independently as my final undergraduate project: an 18-minute hand-drawn psychological animated film inspired by OMORI. I handled the animation, editing, sound design and post-production, creating more than 30,000 hand-drawn frames throughout development. The project received 92% and has since reached more than 36,000 views on YouTube. The project remains one of the strongest examples of my ability to take a large, ambitious idea from concept to a finished piece through self-directed development, iteration and attention to detail.

Simple 3D Render Engine | Real-Time Java Graphics Demo

Simple 3D Render Engine is a lightweight 3D graphics project built in pure Java with Swing, designed to turn mathematical rendering concepts into something visual and interactive. It uses matrix transformations, 3D projection, Z-buffering, and surface normal lighting to render real-time 3D objects with live rotation and visual feedback.
